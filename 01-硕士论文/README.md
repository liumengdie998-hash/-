# 01 硕士论文

## 当前论文

题目：**教学评一体化视域下初中生物大概念教学实践研究**

## 项目定位

本目录是硕士论文的长期研究工作区，用于集中保存研究设计、文献、调查、教学实践、数据分析、论文正文及不同版本，并通过 Git 提交记录重要修改。

## 目录结构

- `01-研究设计/`：研究缘起、意义、目的、思路、方法、技术路线
- `02-文献综述/`：教学评一体化、大概念教学、初中生物大概念教学、文献述评
- `03-文献矩阵/`：文献编码、核心观点、研究方法、研究结论、可借鉴内容
- `04-现状调查/`：学生问卷、教师访谈、信效度、数据分析
- `05-教学实践/`：教学案例、行动研究、课堂观察、教学反思
- `06-数据分析/`：统计结果、图表、分析记录
- `07-论文正文/`：各章节正式稿
- `08-论文版本/`：开题稿、中期稿、修改稿、最终稿

## 研究方法

文献研究法、案例分析法、访谈法、问卷调查法、行动研究法、课堂观察法。

## 当前核心研究链条

理论与文献梳理 → 现状调查 → 问题诊断 → 教学框架构建 → 教学设计 → 课堂实施 → 课堂观察 → 多元评价 → 反思修正 → 实践路径提炼

## 与 ChatGPT 配合

每完成一个重要研究成果，原则上保存：

1. 原始材料
2. AI 分析稿
3. 人工修改稿
4. 最终定稿

重要版本不要直接覆盖，以便追踪研究思路和修改过程。

## 文件命名建议

使用“主题 + 状态/版本 + 日期”的方式命名，例如：

- `研究目的_当前版.md`
- `学生问卷_正式版.docx`
- `文献矩阵_2026-09-05.xlsx`
- `第三章教学实践_V2.md`

> 本目录中的研究框架属于当前工作版本。涉及最终论文结构、样本、统计方法和研究结论的内容，应以实际研究数据及导师最终意见为准。
