# 01 硕士论文

## 当前论文

题目：**教学评一体化视域下初中生物大概念教学实践研究**

## 建议结构

- `01-研究设计/`：研究缘起、意义、目的、思路、方法、技术路线
- `02-文献综述/`：教学评一体化、大概念教学、初中生物大概念教学、文献述评
- `03-文献矩阵/`：文献编码、核心观点、研究方法、研究结论、可借鉴内容
- `04-现状调查/`：学生问卷、教师访谈、信效度、数据分析
- `05-教学实践/`：教学案例、行动研究、课堂观察、教学反思
- `06-数据分析/`：统计结果、图表、分析记录
- `07-论文正文/`：各章节正式稿
- `08-论文版本/`：开题稿、中期稿、修改稿、最终稿

## 研究方法

文献研究法、案例分析法、访谈法、问卷调查法、行动研究法、课堂观察法。
