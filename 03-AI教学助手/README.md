# 03 AI 教学助手

目标：逐步建立一个面向生物教师的个人 AI 教学助手资料库。

## 建议结构

- `01-知识库/`：课程标准、教材、大概念理论、教学评一体化理论
- `02-提示词/`：教学设计、文献分析、PPT、试讲稿、课堂反思等提示词
- `03-工作流/`：从资料输入到教学成果输出的标准流程
- `04-案例/`：优秀课例与 AI 分析结果
- `05-版本记录/`：重要提示词和工作流迭代

## 使用方式

以后可以把 ChatGPT 当作“执行层”，把 GitHub 当作“长期资料层”。

例如：

> 读取 `01-知识库/` 中与七年级细胞分裂有关的材料，按照 `02-提示词/` 的教学设计流程，生成一份 12 分钟微课方案。

长期目标不是学习编程，而是建立自己的可复用教学系统。
