这是我的长期科研、教学、学习与职业发展资料库，配合 ChatGPT、GitHub、Canva、数据分析工具使用。

## 使用原则

1. 重要成果先保存，再继续修改。
2. 每次较大的修改都提交一次 Commit，留下版本记录。
3. 正在进行的任务使用 Issue 管理。
4. 稳定版本与实验版本分开，避免覆盖旧成果。
5. 涉及个人隐私、学生隐私、未公开论文数据的文件不要上传到公开仓库。

## 推荐工作流

**提出任务 → ChatGPT 分析 → 形成文件 → GitHub 保存 → Commit 留痕 → 后续继续修改 → 最终形成可复用资产**
